The public manifests are docs/runtime-models.json (six rigged driving models)
and docs/portrait-models.json (six separate standing portraits). They list
final model paths, compressed/decoded byte sizes and SHA-256 checksums.
Standing portraits derive from the original standing character meshes before
driving-rig and pose edits. Gemini uses the approved center-only character.
Portrait geometry is optimized for browser preview; embedded textures are
retained, and portraits contain no driving rig or driving animations.

Only final runtime GLBs, losslessly gzip-compressed, are included. No character
Blender projects, raw high-poly originals, separate textures, work files or
private source references are distributed. Non-runtime private metadata has
been removed. Geometry optimization is a separate portrait preparation step;
lossless gzip describes the final archive compression, not that optimization.

The corresponding-source ZIP intentionally does not duplicate either set of
large character archives. A full repository clone includes both sets. The
source ZIP includes both checksum manifests and all corresponding game code,
tests and build scripts. Rebuilding code from it works without character
archives; for the complete visuals, run npm run models:fetch to restore the
verified files under public/assets/drivers/ and public/assets/portraits/.
This dev source retrieves from the isolated public /dev/ preview, whose new
portraits are not part of the preserved stable root. The original kart/prop
Blender sources were already public and remain included for their AGPL
corresponding-source completeness.
