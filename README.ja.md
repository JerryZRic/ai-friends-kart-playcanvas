# AI Friends Kart · PlayCanvas 版

PlayCanvas Engine + TypeScript + Vite に移植した独立 HTML プロジェクトです。旧プロジェクトは変更せず、Windows パッケージ化は後回しにしています。6 人のスキン付きドライバー、5 台の AI、3 周レース、ドリフト、アイテム、カメラ、タッチ操作、ローカル GLB 置換を維持します。

[デモ](https://jerryzric.github.io/ai-friends-kart-playcanvas/) · [詳しい説明](README.md)

Node.js 22.12+：npm ci、npm test、npm run build、npm run preview。HTTP で開いてください。コードとオリジナル素材は AGPL-3.0-only。6 人のキャラクターには別途非商用の制限があります（MODEL-NOTICE.txt）。クラウドブラウザーの WebGL は無効のため、実 GPU での表示・操作は別途確認が必要です。
