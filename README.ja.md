Three.js で作ったオリジナルの WebGL アーケードカートレースです。アセットは Blender 4.3.2 で制作・エクスポートしており、編集可能なソースも付属しています。

**[ブラウザーでプレイ](https://cici-neon-kart.shtw.chatgpt.site)**

## 機能

- 夕暮れの海岸コース、海面シェーダー、指向性ライトの影、遠近感のある追従カメラ
- 6 台でのレース、手動アクセル、ブレーキと後退、ハンドブレーキドリフト、ドリフトブースト
- 3 種類のアイテム、周回数と順位の表示、一時停止、リスタート
- 2 種類の追従カメラ、マウスによる視点回転、一時的な後方視点、タッチ操作
- 編集可能なオリジナルの Blender モデルと、単体で動作する静的 Web ビルド

## 動作要件

- WebGL が有効なブラウザー
- ビルドやチェックの実行には Node.js と npm が必要です。このリリースは Node.js 24.19.0 と npm 11.9.0 で検証しました
- 記載のローカル HTTP サーバーコマンドには Python 3 が必要です
- モデルの編集や再生成には Blender 4.3.2 が必要です。プレイには不要です

## クイックスタート

```bash
git clone https://github.com/JerryZRic/neon-kart.git
cd neon-kart
npm ci
npm run check
npm test
npm run build
npm run test:dist
npm run serve
```

[http://localhost:4173](http://localhost:4173) を開きます。

`dist/` フォルダーだけで動作します。バンドル済みの Three.js レンダラー、4 つの GLB アセットすべて、ライセンスとソースコードに関する通知を含み、CDN へのリクエストは不要です。`index.html` を `file:` URL で直接開くのではなく、HTTP サーバー経由で配信してください。付属のビルド済み `dist/` は再ビルドせずに配信できます。

## GitHub Pages と独立したホスティング

**`dist/` の中身をすべて**静的サイトとして配信できます。相対パスのため、ドメイン直下、`/neon-kart/`、その他のサブディレクトリで動作します。ChatGPT アカウント、Sites サービス、CDN、バックエンドは不要です。`.nojekyll`、`source.html`、`source.zip` とすべてのライセンス通知を一緒に配置してください。ゲーム内の **Source / License · 源码与许可证**リンクから、編集可能な Blender ファイルを含むプロジェクトの全ソースを同じサイト上で取得できます。

用意された [Pages ワークフロー](.github/workflows/pages.yml)は `dist/` を直接アップロードします。**手動実行のみ**で、公開チェックボックスの明示的な選択が必要です。プッシュでは公開されません。内容を確認して公開を承認した後、**Settings → Pages → GitHub Actions** を選択し、Actions から **Publish static game to GitHub Pages** を実行します。現時点ではファイルを準備しただけで、Pages の有効化や新しいサイトの公開は行っていません。非公開リポジトリでも Pages サイトは通常公開され、配信時には `source.zip` も公開されます。

ブランチからの Pages 公開では `/(root)` または `/docs` のみ選択でき、`/dist` は直接選べません。上記ワークフローを推奨しますが、配信ファイル一式を対応する場所にコピーする方法もあります。`npm run test:dist` でルートとネストしたパスの HTTP 配信を検査できます。構成、代替手順、検証範囲は[独立配信ガイド](docs/github-pages.md)を参照してください。

## 操作

| 入力 | 動作 |
| --- | --- |
| `W` / `↑` | アクセル。離すと惰性走行します。加速は手動です。 |
| `A` / `←`, `D` / `→` | 車両を基準に左右へステアリングします。 |
| `S` / `↓` | 前進中はブレーキ。押し続けると停止後に後退します。 |
| `Space` | 後退せず、完全に停止するまでブレーキをかけます。 |
| `Left Shift` + ステアリング | ハンドブレーキドリフト。Shift を離すとドリフトブーストが発動します。 |
| `E` | 獲得したアイテムを使います。 |
| `Z` | 2 種類の追従カメラを切り替え、視点を中央に戻します。`C` でも同じ操作ができます。 |
| マウスの右ボタンを押し続ける | 一時的に後方を見ます。離すと元の視点角度に戻ります。 |
| コースをクリックしてマウスを動かす | ポインターをロックし、カメラを水平方向に 360° 回転させます。上下の視点移動は滑らかで、角度に制限があります。 |
| `Q` | 視点を滑らかに中央へ戻します。 |
| `Esc` | 一時停止し、ポインターのロックを解除します。 |
| `P` / 一時停止ボタン | 一時停止と再開を切り替えます。 |

一時停止後は、コースをクリックするとゲームが再開し、ポインターが再びロックされます。`P` / 一時停止ボタンでは、ポインターをロックせずに再開できます。ポインターのロックが使えない場合は、マウスの左ボタンを押しながらドラッグして視点を動かせます。

タッチ操作では、左右のステアリング、ドリフト、ブレーキ、後退、アクセルを使用できます。アイテムパネルをタップするとアイテムを使います。

該当する運転キーの配置は、公開されている NTE の PC 操作に合わせています。[操作資料](https://gamewith.net/nte/75764)と[ゲーム内 HUD 画像](https://img.gamewith.net/img/original_c5318b60d191081761bb0516dadb5cd4.png)では、Space がブレーキ、Left Shift がハンドブレーキ、Z がカメラ切り替え、マウス右ボタンが後方視点に割り当てられています。アイテムに使う `E` は Neon Kart 独自の割り当てです。本作は車線に沿って走るアーケードレースであり、NTE の車両物理やその他の車両機能を再現するものではありません。

## 編集可能なモデル

Blender で `models/kart.blend` と `models/props.blend` を開いてください。元のパーツとマテリアルを編集できます。アセットを再生成するには、次のコマンドを実行します。

```bash
blender -b --python models/build_models.py
blender -b --python models/create_props.py
```

スクリプトは `models/` にエクスポートします。再ビルドする前に、生成された `kart.glb`、`palm.glb`、`rock.glb`、`arch.glb` を `dist/assets/` にコピーしてください。GLB は Y 軸を上方向とし、カートは +Z 方向を向いています。`Body` と `Helmet` のマテリアルは色を変更できます。

Blender アセットはすべて、このゲームのために制作したオリジナル作品であり、プロジェクトのライセンスが適用されます。Blender 自体は外部の制作ツールで、同梱していません。

## リポジトリ構成

- `src/vehicle-controls.js`: 物理キーの割り当て、手動アクセル、ブレーキと後退、正負の方向を扱うステアリング
- `src/mouse-look.js`: 滑らかな視点回転、上下角度の制限、ポインターロックのライフサイクル、ドラッグ操作へのフォールバック
- `src/game.js`: Three.js シーン、カメラ、コース、レーサー、ドリフトブースト、アイテム、周回数、順位
- `src/index.html`: レスポンシブ対応の中国語 UI と操作パネル
- `models/`: 編集可能な Blender ソース、手続き型モデリングスクリプト、モデルのメタデータ
- `tests/`: マウス視点、車両操作、ゲームプレイのシミュレーションチェック
- `build.mjs`: esbuild によるバンドルとライセンス・ソースコード通知のコピー。ローカルの GLB アセットを保持します
- `dist/`: 配信可能な静的ゲーム、4 つの GLB、必要な通知
- `docs/releases/`: リリースの出典と検証

## 検証

JavaScript の構文チェック、**操作・カメラ・ゲームプレイのシミュレーションチェック全 34 件**、ビルドが通過しました。ゲームの JavaScript と GLB は公開済み安定版とバイト単位で一致します。ソース HTML は変更せず、配信用 HTML にソースとライセンスへの可視リンクだけを追加します。4 つの GLB すべてに外部バッファーや画像への参照はなく、編集可能な Blender ファイル 2 つにも外部ライブラリー、画像、フォント、スクリプトへのリンクはありません。[リリースの検証](docs/releases/v1.0.0.md)を参照してください。

元のビルドは、Blender でのエクスポート、再インポート、スタジオレンダリングのチェックと、Three.js での GLB 解析、マテリアルのバッチ処理の検証にも通過しています。シミュレーションは次の項目をカバーしています。360 通りの向きでのステアリングとヨー、両方の追従カメラによるコース上 32 地点での投影、滑らかなマウス視点移動、上下角度の制限、無制限の水平回転、視点の中央復帰、繰り返しクリックによるポインターロックと複数マウスボタン同時押し後の解放、予期しないロック解除と意図的なロック解除、一時停止後に遅れて成立するロック、ロック失敗とドラッグ操作へのフォールバック、後方視点からの復帰、ブレーキと後退、アイテム、一時停止時の入力解除、タッチ操作、レースとリスタートのロジックです。

公開 Site はサインインせずに開けましたが、クラウドのテスト用ブラウザーは `GL_VENDOR = Disabled` / `GL_RENDERER = Disabled` と報告し、WebGL コンテキストを作成できませんでした。そのため、描画されたゲームプレイとネイティブのポインターロックの操作感は、**そのブラウザーでは未検証です**。シミュレーションスイートでは、実際の Three.js のカメラ・ジオメトリとゲームロジックを、モックのレンダラーと DOM で動かしています。ブラウザーで描画されたゲームを目視確認した結果ではありません。
