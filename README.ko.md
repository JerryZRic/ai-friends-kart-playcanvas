# AI Friends Kart · PlayCanvas 버전

PlayCanvas Engine + TypeScript + Vite로 옮긴 독립 HTML 프로젝트입니다. 기존 프로젝트는 그대로 유지하며 Windows 패키징은 나중에 진행합니다. 스킨이 있는 6명 캐릭터, AI 5명, 3바퀴 경기, 드리프트, 아이템, 카메라, 터치 조작과 로컬 GLB 교체를 유지합니다.

[데모](https://jerryzric.github.io/ai-friends-kart-playcanvas/) · [자세한 설명](README.md)

Node.js 22.12+: npm ci, npm test, npm run build, npm run preview. HTTP로 열어 주세요. 코드와 원본 자체 제작 자산은 AGPL-3.0-only이며 캐릭터 6종은 별도 비상업적 제한이 적용됩니다(MODEL-NOTICE.txt). 클라우드 브라우저는 WebGL이 비활성화되어 있어 실제 GPU 화면과 조작은 별도 검증이 필요합니다.
