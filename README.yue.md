# AI Friends Kart · PlayCanvas 移植版

呢個係獨立 HTML 項目，用 PlayCanvas Engine + TypeScript + Vite；舊版唔會改，Windows 打包遲啲先做。保留六個可選骨骼角色、五個 AI、三圈比賽、飄移、道具、鏡頭、觸控同本機 GLB 替換。

[試玩](https://jerryzric.github.io/ai-friends-kart-playcanvas/) · [完整說明](README.md)

Node.js 22.12+：npm ci、npm test、npm run build、npm run preview。要用 HTTP 開啟，唔好直接用 file://。程式同原創資產係 AGPL-3.0-only；六個角色另外有非商業限制，睇 MODEL-NOTICE.txt。雲端瀏覽器停用咗 WebGL，真實 GPU 遊戲畫面仲要驗證。
