# AI Friends Kart · PlayCanvas 移植版

獨立 HTML 專案，使用 PlayCanvas Engine + TypeScript + Vite；舊專案不變，Windows 打包暫緩。保留六個可選骨骼角色、五名 AI、三圈賽事、漂移、道具、相機、觸控與本機 GLB 替換。

[試玩](https://jerryzric.github.io/ai-friends-kart-playcanvas/) · [完整說明](README.md)

Node.js 22.12+：npm ci、npm test、npm run build、npm run preview。以 HTTP 開啟；不支援直接 file://。程式與原創資產採 AGPL-3.0-only；六個角色另有非商業限制，詳見 MODEL-NOTICE.txt，不因開放程式碼而重新授權。雲端瀏覽器停用 WebGL，真實 GPU 遊玩尚需驗證。
