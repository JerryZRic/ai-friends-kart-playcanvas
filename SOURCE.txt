The source ZIP excludes six large character .glb.gz files; the repository includes them.
The exact separately served paths/sizes/hashes are in docs/runtime-models.json.
After extracting source.zip, npm ci; npm run models:fetch; npm run build.
Without character files the game builds with explicit original-driver fallbacks.
Run npm run preview and open its HTTP URL. Do not use file://.
All runtime dependencies/assets are served beside the game. No ChatGPT login, CDN,
model API, telemetry or external service is required for gameplay.
Local replacements remain only in page memory and are never uploaded or persisted.
