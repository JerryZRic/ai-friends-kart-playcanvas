The source ZIP excludes all twelve character .glb.gz archives: six driving models
and six standing portraits. The repository includes both separately licensed sets.
Paths/sizes/hashes are in docs/runtime-models.json and docs/portrait-models.json.
This dev source restores verified archives from the isolated public /dev/ preview.
After extracting source.zip, npm ci; npm run models:fetch; npm run build.
Code builds without character archives; restore both sets for the complete visuals.
Run npm run preview and open its HTTP URL. Do not use file://.
All runtime dependencies/assets are served beside the game. No ChatGPT login, CDN,
model API, telemetry or external service is required for gameplay.
Local replacements remain only in page memory and are never uploaded or persisted.

Keep source.html, source.zip, LICENSE, NOTICE, SOURCE.txt, MODEL-NOTICE.txt and
THIRD-PARTY-NOTICES.txt beside the deployed game.
