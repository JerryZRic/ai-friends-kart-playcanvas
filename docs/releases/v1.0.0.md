# v1.0.0 — Original stable baseline

This is the first stable GitHub release of Neon Kart 3D · Sunset Coast.

## Snapshot identity

- Original published game: Sites version 5
- Original source commit: `27e465a74e2248bc2584b77e3987ea2bb88d39dd`
- Public game: https://cici-neon-kart.shtw.chatgpt.site
- Original publication verified on 2026-10-02: succeeded
- Stable game export: 25 source/runtime files before release metadata additions; private deployment configuration is excluded

Sites version numbers and GitHub semantic release tags use different counters. This release starts the GitHub stable release line at `v1.0.0`; it does not revert the game to Sites version 1. The pre-release package version `2.0.0` is normalized to `1.0.0` in `package.json` and `package-lock.json`.

## Included

- Original browser game source, responsive interface, camera and vehicle controls
- Prebuilt browser bundle and four original Blender-exported GLB assets: kart, palm, rock and arch
- Editable `kart.blend` and `props.blend`, original procedural modeling scripts and model metadata
- Pinned dependencies, build script and 34 simulation/regression checks
- Byte-level provenance in `v1.0.0-original-source.json`

Unreleased character integrations and later model experiments are excluded.

## Verification

Verified on 2026-10-02 with Node.js 24.19.0, npm 11.9.0 and Blender 4.3.2:

- JavaScript syntax checks passed
- All 34 mouse-look, vehicle-control and gameplay simulation checks passed
- Building from the exact stable gameplay source reproduces the published runtime JavaScript byte-for-byte; standalone distribution packaging adds only a visible Source / License anchor to the original HTML
- All four GLBs contain no external buffer or image references
- Both editable Blender files contain no linked external libraries, image assets, fonts or scripts
- Standalone distribution checks pass at `/`, `/neon-kart/`, and `/preview/nested/game/`, including local source/archive and license links
- The source ZIP is repeatable for identical input files and includes only explicitly allowlisted project files

Simulation tests use the real Three.js camera and game logic with a mocked renderer and DOM. They are not a visual browser gameplay pass. The existing cloud test browser could not create a WebGL context; this release does not claim new visual or pointer-lock hardware testing.

## Release scope

Gameplay source, runtime bundle and exported GLB model bytes are preserved from the identified stable snapshot. The editable Blender files retain their original geometry and materials; only the saved render-output filepath field is changed to a portable relative path. Approved release additions are the AGPL-3.0-only license, explicit original-code/model scope, retained MIT notices, source-download information, release provenance, and package version/license metadata. The build script additionally packages license/source notices, a visible Source / License anchor in distribution HTML, a local source page and deterministic corresponding-source ZIP, and `.nojekyll`. The original `src/index.html`, game bundle and GLB assets remain unchanged. A manual-only Pages workflow and static subpath/HTTP checks are included; no repository settings or deployment are changed.

The playable Site is unchanged by this archival GitHub release. No new character integrations, reference images, reference video or experimental work are included.

## Privacy and portability

Private deployment configuration is excluded. Public source files contain no account-linked deployment project identifiers or cloud workspace paths. Editable Blender source uses relative render-output paths. Original runtime and exported model bytes are unchanged.
